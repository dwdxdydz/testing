# Ajit Pal Singh — 3D Portfolio Testing Project

## What is this?

This repository is a standalone HTML/CSS/JavaScript portfolio project.

It is also used to practise **frontend testing**.

The website has a 3D/glass design and contains my professional profile, projects, skills and links.

## What the website contains

- About
- Experience
- Projects
- Skills
- Open Source
- Contact
- GitHub link
- LinkedIn link

## 3D effects

The design uses normal CSS and JavaScript.

It includes:

- 3D cards
- Pointer-based card rotation
- Glass-style panels
- Floating elements
- CSS 3D cube
- Perspective effects
- Hover effects

No Three.js is required.

## Testing

The project uses Node.js's built-in test runner.

Run:

```bash
npm test
```

The tests check things such as:

- Required files exist
- No duplicate HTML IDs
- Internal navigation links work
- CSS and JavaScript files exist
- External links use safe attributes
- JavaScript syntax is valid
- Portfolio sections exist
- GitHub project links exist
- LinkedIn link exists
- Profile information exists
- Contact information exists
- SEO metadata exists
- Accessibility attributes exist
- Responsive CSS exists
- Reduced-motion support exists
- 3D features are present

## Files

- `index.html` — website content
- `style.css` — design and 3D styling
- `script.js` — interaction and animation
- `tests/portfolio.test.js` — automated tests
- `package.json` — test command

## Run locally

You can open `index.html` directly.

Or use a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
